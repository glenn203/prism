Default motion is now opt-in through the polish layer (`data-prism-polish` with `motion`, `all`, or an empty attribute). Press-scale, the invalid-field nudge, the floating-label spring, checkbox and radio squish, the check-mark draw, and the segmented indicator springs only play when that scope is on. Without it, the default stays still and readable: a segmented control uses a static selected surface, and a check mark simply appears. The switch is unchanged. Helpers and public names are unchanged.
